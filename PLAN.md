## 2. Адаптивность и отсутствие прокрутки (пп. 1.10.1–1.10.2)

- [x] Перестроить layout в [`css/style.css`](css/style.css): убрать правило `body { overflow-y: auto; }`
  из мобильного media-query и задать `html, body` фиксированную область viewport без браузерной
  прокрутки, включая iOS/Android (`dvh` с безопасным fallback).
- [x] Заменить жёсткий CSS-размер canvas `500px × 500px` на вычисляемый квадрат, ограниченный
  одновременно доступными шириной и высотой viewport. Учесть границу canvas, header, toolbar,
  HUD, подсказку, вертикальный/горизонтальный регулятор, `safe-area-inset-*` и минимальные
  размеры текста/кнопок. Не менять внутренние `width`/`height` canvas 500×500, чтобы не нарушить
  игровую сетку; масштабировать только его CSS-представление.
- [x] Добавить breakpoints по высоте, а не только по ширине: на низком ТВ/горизонтальном экране
  компактно уменьшать интервалы и второстепенные элементы; на узком телефоне переносить элементы
  без выхода за край. Модальные окна и overlay также ограничить фактической высотой viewport.
- [x] Проверить в DevTools и на целевых устройствах: портрет/ландшафт Android и iOS, 320×568,
  360×640, 768×1024 и ТВ 1280×720/1920×1080. На каждом размере нет горизонтальной или вертикальной
  прокрутки, а нижние кнопки и overlay целиком достижимы.

## 3. Безопасное взаимодействие с игровым полем (пп. 1.6.2.7 и 1.6.1.8)

## 4. LoadingAPI / GameReady (п. 1.19)

- [x] Разделить в [`js/game.js`](js/game.js) подготовку данных и открытие игры. До завершения

## 5. ТВ и управление с пульта (пп. 1.14, 1.6.3.2, 1.10.1)

- [x] Сделать явную модель фокуса для ТВ в [`js/game.js`](js/game.js): во время раунда стрелки

  кнопкам, `Enter`/`Space` активирует выбранную, `Back`/`Escape` возвращает назад. Начальный
  фокус после поражения — «Новая игра», поэтому продолжение не требует перезапуска приложения.
- [x] Обеспечить нативную клавиатурную доступность всех кнопок (`button`, видимый `:focus-visible`,

  При необходимости добавить обработку стандартных кодов пультов, не полагаясь только на `key`.
- [x] Проверить на ТВ полный сценарий: запуск → управление змейкой стрелками → поражение → выбор

  отзывчивость после нескольких раундов и убедиться, что не накапливаются `requestAnimationFrame`,
  таймеры рекламы или обработчики; устранить найденную причину зависания до релиза.
- [x] Повторить визуальную проверку ТВ после адаптивной правки: нижняя часть экрана, overlay и
  все доступные по пульту элементы не обрезаются.

## Сессия 26–27.07.2026 — отправка на модерацию

**Проблема:** игра в черновике открывалась «голым» HTML без стилей и логики.
**Причина:** все архивы, собранные PowerShell `Compress-Archive`, содержали пути
с обратными слэшами (`css\style.css`) — хостинг Яндекса (S3) не распаковывал
вложенные файлы и отдавал `NoSuchKey`.

**Сделано:**
- Пересобран корректный архив `yandex-game-v2.zip` (.NET ZipFile, пути через `/`), загружен в консоль — игра в черновике полностью работает (стили, канвас, режимы, автопилот, облачные сохранения проверены вживую).
- Подтверждена SDK-интеграция: `YaGames.init()` в `<head>`, `LoadingAPI.ready()`, `GameplayAPI.start()/stop()`, язык через `ysdk.environment.i18n.lang`, звук паузится при потере фокуса и при рекламе, контекстное меню отключено.
- Заполнен чеклист публикации (23/23), **игра отправлена на модерацию 27.07.2026**. Черновик заблокирован до окончания проверки.
- Репозиторий прибран: удалены 4 битых архива, изменения закоммичены (`a636ca5`).

**Как собирать архив впредь:** не использовать старый `Compress-Archive`;
пересборка — .NET `ZipFile`/`CreateEntryFromFile` с именами через `/`
(или любой стандартный zip-инструмент). Проверять entries перед загрузкой.

Сейчас в игре только реклама РСЯ: interstitial (`showFullscreenAdv`) и
