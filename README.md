# 🐍 Змейка: Автопилот

«Змейка: Автопилот» — браузерная игра на чистом JavaScript (canvas, без зависимостей и сборки) с автопилотом (алгоритм BFS + lookahead, не нейросеть), скинами, тремя режимами игры и монетизацией под платформу **Яндекс Игры**. Англоязычное название: **Snake: Autopilot**.

## Запуск локально

Нужен любой статический сервер (модули ES требуют http, двойным кликом по файлу игра не откроется):

```bash
python -m http.server 8000
```

Затем открыть <http://localhost:8000>.

Без SDK какой-либо площадки игра запускается на **mock-платформе**: реклама «показывается» мгновенно, rewarded всегда засчитывается, сохранения идут в `localStorage`. В консоли будет строка `Platform: mock` — это нормально. Полезные параметры адреса: `?platform=mock` (принудительно mock) и `?lang=en` (английская локализация).

Сборка под конкретную площадку:

```bash
node tools/build.mjs yandex     # build/yandex/ + build/yandex.zip
node tools/build.mjs --all
```

## Структура проекта

```
snake/
├── index.html               — разметка + маркер, куда сборка вставляет SDK площадки
├── css/style.css            — все стили
├── js/boot.js               — composition root: собирает платформу и запускает игру
├── js/platform.config.js    — какая площадка у этой сборки
├── js/core/                 — GAME CORE: game.js (логика, ИИ, отрисовка) и i18n.js
├── js/platform/core/        — абстракции: сервисы, модели, события, ошибки, фабрика
├── js/platform/mock/        — адаптер локальной заглушки (без SDK)
├── js/platform/yandex/      — адаптер Яндекс Игр (единственный файл с YaGames)
├── tools/build.mjs          — сборка билда под площадку + zip
├── docs/platform-architecture.md — платформенная архитектура подробно
├── assets/                  — иконка 512×512 и обложка 800×470 для карточки Яндекс Игр
├── image.png                — скриншот для README
└── README.md
```

Принцип: `js/core/` не знает, на какой площадке запущен, и обращается только к абстракциям из `js/platform/core/` — готовый набор сервисов приходит извне, из `boot.js`. Портирование на новую площадку сводится к новому адаптеру и строке в реестре, игровой код при этом не меняется — см. [docs/platform-architecture.md](docs/platform-architecture.md).

## Геймплей

| Возможность | Описание |
|---|---|
| **Режимы** | Классика (стены убивают) · Без стен (проход сквозь края) · Препятствия (14 блоков; генерация с проверкой связности поля, зона старта всегда свободна) |
| **Управление** | Стрелки / WASD (работает на любой раскладке через `e.code`), свайпы на мобильных, `P`/`Esc` — пауза |
| **ИИ-автопилот** | Кнопка «✨ Авто»: BFS до еды + погоня за хвостом + lookahead на 8 ходов; понимает все режимы |
| **Еда** | 🍎 обычная +10 очков, ⭐ бонусная +30 (появляется на каждых кратных 50 очках) |
| **Скорость** | Слайдер 3–500 мс/ход; автоускорение каждые 50 очков |
| **Звук** | WebAudio-синтез (без файлов): еда, бонус, смерть, покупка, возрождение; кнопка 🔊/🔇 |

## Экономика и монетизация

Дизайн строится вокруг трёх точек показа рекламы — все идут через `platform.ads`, а не через SDK напрямую:

1. **Rewarded «Возродиться»** (экран поражения) — счёт и монеты сохраняются, змейка стартует заново. Один раз за раунд. Самая доходная точка: игрок мотивирован сохранить прогресс.
2. **Rewarded «Удвоить очки»** (экран поражения) — x2 к финальному счёту перед отправкой в лидерборд. Один раз за раунд.
3. **Interstitial** между раундами — при нажатии «Новая игра». Кулдаун 65 секунд, первый раунд никогда не прерывается (требование модерации Яндекс Игр).

Дополнительно: скин «Призрак» выдаётся за просмотр rewarded — четвёртая точка показа.

**Мягкая валюта (монеты 🪙):** +1 за еду, +5 за бонус, +100 за победу (заполненное поле). Тратятся в магазине скинов:

| Скин | Цена |
|---|---|
| Классика | бесплатно |
| Неон | 150 🪙 |
| Огонь | 300 🪙 |
| Призрак | 📺 за рекламу |
| Золото | 600 🪙 |
| Радуга (анимированная) | 1000 🪙 |

**Сохранения:** объект `save` (монеты, рекорд, купленные скины, выбранный скин, режим, звук) пишется в облако игрока Яндекса (`player.setData`) и дублируется в `localStorage`. При запуске рекорд из старой версии игры мигрирует автоматически.

**Лидерборд:** лучший счёт отправляется в лидерборд с техническим именем `snakeScore` (нужно создать в консоли разработчика, см. ниже).

## Интеграция с площадками — общий порядок

Порядок одинаков для любой площадки, и ни один шаг не затрагивает игровой код в `js/core/`.

1. **Завести приложение в консоли площадки** и выяснить её требования: откуда подключается SDK, что обязательно вызвать при старте, где хостится билд.
2. **Написать адаптер** `js/platform/<id>/<id>-platform.js`: реализовать только те сервисы, которые площадка умеет, перевести её объекты в модели проекта (`AdResult`, `PlayerData`, …), события — в `PlatformEvent`, ошибки — в `PlatformError`. Всё, чего у площадки нет, просто не передавать в `PlatformServices` — базовые заглушки честно ответят «не поддерживаю», а игра сама скроет соответствующие кнопки через `capabilities`.
3. **Зарегистрировать адаптер** — одна строка в `ADAPTERS` в [js/platform/core/factory.js](js/platform/core/factory.js).
4. **Добавить площадку в сборку** — одна запись в `PLATFORMS` в [tools/build.mjs](tools/build.mjs): идентификатор, описание и `head` с загрузчиком SDK.
5. **Собрать и проверить**: `node tools/build.mjs <id>`. Сначала локально (без SDK фабрика подставит mock — игра обязана запускаться), затем в песочнице площадки с настоящим SDK.
6. **Загрузить билд, настроить лидерборд и монетизацию, отправить на модерацию.**

Подробности архитектуры и шаблон адаптера — в [docs/platform-architecture.md](docs/platform-architecture.md).

## Яндекс Игры — реализовано

Всё в [js/platform/yandex/yandex-platform.js](js/platform/yandex/yandex-platform.js) — это единственный файл проекта, который знает про `YaGames`.

| Сервис проекта | Вызов Yandex Games SDK |
|---|---|
| `LifecycleService.notifyReady()` | `features.LoadingAPI.ready()` — **обязательное требование модерации**, вызывается после загрузки сохранений и первой отрисовки |
| `LifecycleService.gameplayStart/Stop()` | `features.GameplayAPI.start()/stop()` — старт раунда, пауза, магазин, экран поражения |
| `AdsService.showInterstitial()` | `adv.showFullscreenAdv`; кулдаун 65 с и пропуск первого раунда — в `InterstitialPolicy` |
| `AdsService.showRewarded()` | `adv.showRewardedVideo`; награда только после `onRewarded` |
| `StorageService` | `player.getData()/setData()` + `localStorage` как резерв |
| `LeaderboardService` | `leaderboards.setScore('snakeScore', …)` |
| `PlayerService` | `getPlayer({ scopes: false })` — без запроса персональных данных, работает и для анонимов |
| `PlatformEvent.PAUSE/RESUME` | события `game_api_pause` / `game_api_resume` |
| `extensions.stickyBanner` | `adv.showBannerAdv()/hideBannerAdv()` — возможность только этой площадки |

Особенность площадки: тег `/sdk.js` и `YaGames.init()` должны стоять прямо в `<head>` и грузиться с домена Яндекса — их подставляет сборка. Если SDK не ответил, фабрика логирует предупреждение и подставляет mock, чтобы игра всё равно открылась.

### Публикация — пошагово

1. **Аккаунт разработчика.** Зайти в [Консоль разработчика Яндекс Игр](https://games.yandex.ru/console/) под Яндекс-аккаунтом, принять условия.
2. **Создать черновик игры** («Создать игру»), указать одинаковое название во всех полях: «Змейка: Автопилот» для RU и «Snake: Autopilot» для EN.
3. **Собрать архив.** `node tools/build.mjs yandex` — получится `build/yandex.zip` с `index.html` в корне, подставленным загрузчиком SDK и только нужными файлами.
4. **Загрузить архив** во вкладке «Файлы игры», отметить использование SDK v2.
5. **Создать лидерборд**: вкладка «Лидерборды» → имя `snakeScore`, тип «числовой», порядок «больше — лучше». Имя должно совпадать с `LEADERBOARD_NAME` в `js/platform/yandex/yandex-platform.js`.
6. **Заполнить карточку**: описание (RU), категория «Аркады», возрастной рейтинг, обложка и скриншоты (сделать в разных режимах/скинах; требования к размерам показывает сама консоль).
7. **Проверить в песочнице.** Консоль даёт ссылку на черновик — там игра работает уже с настоящим SDK: проверить рекламу, лидерборд, сохранения, мобильную версию (свайпы).
8. **Отправить на модерацию.** Типичные причины отказа, которые у нас уже закрыты: нет `LoadingAPI.ready()`, реклама мимо SDK, игра не адаптивна, внешние ссылки, реклама в первые секунды. Отдельно проверьте, что в архиве нет ссылок на сторонние сайты.
9. **Монетизация.** После публикации в консоли подключить показ рекламы (РСЯ подключается через саму платформу; выплаты — по условиям партнёрской программы Яндекс Игр). Доход виден в разделе статистики.

## VK Игры — план интеграции

Игры ВКонтакте — это VK Mini Apps: страница открывается внутри клиента VK, а всё общение с платформой идёт через библиотеку [VK Bridge](https://github.com/VKCOM/vk-bridge) (`bridge.send(метод, params)` возвращает промис). Адаптера в репозитории пока нет — ниже порядок работ и готовое соответствие сервисов.

### Что делать

1. **Приложение.** На [dev.vk.com](https://dev.vk.com/) создать приложение типа «Игра», указать поддерживаемые платформы (веб, iOS, Android) и базовый HTTPS-URL билда — либо свой хостинг, либо хостинг VK Mini Apps.
2. **Адаптер** `js/platform/vk/vk-platform.js` по таблице ниже: `createPlatform()` дожидается `VKWebAppInit`, собирает `PlatformServices` и возвращает их; если `VKWebAppInit` не прошёл — бросает `PlatformError(NOT_READY)`, и фабрика сама откатится на mock.
3. **Реестр:** `vk: () => import('../vk/vk-platform.js')` в `ADAPTERS`.
4. **Сборка:** запись `vk` в `PLATFORMS` (`tools/build.mjs`), в `head` — подключение UMD-сборки vk-bridge. В отличие от Яндекса, VK не требует грузить SDK со своего домена, поэтому файл можно положить рядом с игрой и подключить локально — так билд не зависит от стороннего CDN.
5. **Проверка:** `node tools/build.mjs vk`, затем открыть приложение внутри VK — на вебе и в мобильном клиенте.
6. **Монетизация и модерация** в настройках приложения VK.

### Соответствие сервисов

| Сервис проекта | VK Bridge |
|---|---|
| `LifecycleService.notifyReady()` | `VKWebAppInit` — обязателен, без него клиент не покажет приложение. Аналога `GameplayAPI` нет: `gameplayStart/Stop` остаются пустыми |
| `AdsService.showInterstitial()` | `VKWebAppShowNativeAds` с `ad_format: 'interstitial'` |
| `AdsService.showRewarded()` | `VKWebAppShowNativeAds` с `ad_format: 'reward'`; награда засчитывается по успешному результату вызова |
| `AdsService.capabilities` | `VKWebAppCheckNativeAds` — реклама доступна не всегда; если её нет, `capabilities.rewarded === false`, и игра сама спрячет «Возродиться» и «x2» |
| `StorageService` | `VKWebAppStorageSet` / `VKWebAppStorageGet`. Хранилище строковое и с лимитом на размер значения — `JSON.stringify`/`parse` и, при необходимости, разбиение по ключам делает адаптер, игра об этом не знает |
| `LeaderboardService` | `VKWebAppShowLeaderBoardBox` с `user_result`. Это диалог, а не «тихая» отправка счёта, и он доступен не на всех платформах: там, где его нет, честнее вернуть `available === false` |
| `PlayerService` | `VKWebAppGetUserInfo` → своя модель `PlayerData` |
| `PaymentsService` | `VKWebAppShowOrderBox` (голоса VK), если появятся платные покупки |
| `Environment.language` | параметр запуска `vk_language` из query-строки |
| `PlatformEvent.PAUSE/RESUME` | прямого аналога `game_api_pause` нет; игра и так реагирует на `visibilitychange`, дополнительных событий адаптер может не слать |

Точные имена и параметры методов сверяйте с документацией VK — они меняются чаще, чем архитектура: [dev.vk.com](https://dev.vk.com/), [VKCOM/vk-bridge](https://github.com/VKCOM/vk-bridge).

### Чего делать не нужно

Ни одной правки в `js/core/`, `index.html` или CSS. Различия площадок — строковое хранилище, отсутствие лидерборда, недоступная реклама, свой способ узнать язык — закрываются внутри адаптера и флагами `capabilities`.

## Дорожная карта

- **Этап 1 — Яндекс Игры** *(текущий)*: режимы, монеты, скины, звук, пауза, rewarded/interstitial, лидерборд, публикация.

- **Этап 3 — Telegram Mini App / CrazyGames**: адаптеры `js/platform/telegram/` и `js/platform/crazygames/`; для Telegram — реклама Adsgram, облачное хранилище и шаринг результата в чат.
- **Идеи в очередь**: ежедневный челлендж (фиксированный seed), экранный джойстик для мобильных, музыка, таймер на бонусную еду, достижения.
